# AGENTS.md — инструкции для ИИ-агентов (Codex, Claude Code)

## Прежде чем писать код
1. Прочитай `SPEC.md` целиком. Это единственный источник правды.
2. Узнай свою роль (1 Генератор, 2 Среда, 3 Оценщик, 4 Интегратор, см. SPEC §17) и правь только свои папки.
3. `src/auditgym/common/` и `SPEC.md` не меняй без явного разрешения человека.

## Команды
- Установка: `uv sync`
- Тесты: `uv run pytest -q`
- Всё сразу: `uv run auditgym all`
- Docker: `make docker`

## Жёсткие правила (SPEC §1)
- Деньги только `int` (minor units), курсы только `Decimal(str)`, никаких float.
- Нет `hash()`, `datetime.now()`, глобального `random`, `uuid4()`, итерации по set/dict без `sorted()`.
- Случайность только через `common/rng.py::stream(name)`.
- Канонический JSON: `sort_keys=True, separators=(",", ":")`.
- Ничего из `private/` (truth, provenance, seed, пути) не попадает в наблюдения, info, ошибки и логи траекторий.
- Сообщения об ошибках для агента — только фиксированные строки из SPEC §8.4.
- Без сети, без платных API, без GPU.

## Как работать
- Сначала коротко напиши план и список тестов, потом код.
- Маленькие шаги: модуль → тесты → `pytest` → следующий модуль.
- Каждое новое поведение покрыто тестом. Не помечай задачу готовой, пока тесты не зелёные.
- Не меняй интерфейсы из SPEC. Если интерфейса не хватает — остановись и опиши, что нужно добавить в SPEC.
- Если нашёл противоречие в SPEC — не угадывай, сообщи человеку.

## Стиль
- Python 3.11, type hints везде, `dataclass(frozen=True)` для данных.
- Docstring у публичных функций: что делает, инварианты, детерминизм.
- Модули маленькие, без глобального состояния.
